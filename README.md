# 🚀 Автоматизация Telegram Ads

Этот скрипт позволяет автоматически создавать рекламные объявления в кабинете Telegram Ads, обходя защиту от ботов с помощью невидимого браузера.

## 🛠 Установка (Один раз при первом запуске)

1. Убедись, что у тебя установлен Python 3.
2. Открой терминал в папке с проектом и установи нужные библиотеки:
   `python3 -m pip install requests playwright --break-system-packages`
3. Скачай браузеры для правильной работы Playwright:
   `python3 -m playwright install`

## 🏃‍♂️ Как запускать

Основной рабочий файл — `create_ad.py`. 
Для запуска просто введи в терминале:
`python3 create_ad.py`
Скрипт сам отправит данные, и объявление появится в кабинете со статусом *On Hold*.

## ⚠️ Важно для работы с разных ПК (Антибан)

Так как мы работаем вдвоем с разных компьютеров, Telegram может сбросить нашу сессию из-за разных IP-адресов. 

* **Если скрипт выдает ошибку авторизации:** 
  Нам нужно обновить файл `session.json`. Запусти скрипт авторизации, залогинься через телефон, и новая сессия сохранится.
* **Срок годности хеша:**
  Периодически Telegram меняет `api_hash`. Если объявление перестало создаваться, нужно заново отловить хеш и обновить переменную `api_hash` внутри `create_ad.py`.
